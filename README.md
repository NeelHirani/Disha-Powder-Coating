# 🎨 Disha Powder Coating

> Professional powder coating services website built with React, Vite, and Tailwind CSS

![Disha Powder Coating](./attached_assets/generated_images/Powder_coating_workshop_hero_d77b1d0b.png)

## 🚀 Features

- ✨ **Modern UI/UX** — Smooth animations with Framer Motion
- 📱 **Fully Responsive** — Mobile-first design with sticky CTAs
- 🎨 **9 Complete Pages** — Home, About, Services, Gallery, Industries, Contact, Quote, Testimonials, FAQ
- 💬 **WhatsApp Integration** — Floating button for instant customer connection
- 🔍 **SEO Optimized** — Structured data (JSON-LD), meta tags, robots.txt
- 📋 **Multi-Step Quote Form** — Professional quote request with file uploads
- 🖼️ **Interactive Gallery** — Filter by category with lightbox modal
- ❓ **Searchable FAQ** — Real-time search through questions
- 🎯 **Conversion Focused** — Multiple CTAs strategically placed throughout

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + CSS Variables
- **UI Components:** Radix UI + shadcn/ui
- **Animations:** Framer Motion
- **Routing:** Wouter (lightweight React Router alternative)
- **Forms:** React Hook Form + Zod validation
- **State:** TanStack Query (React Query)
- **Icons:** Lucide React

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/disha-powder-coating.git

# Navigate to project directory
cd disha-powder-coating

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🏗️ Build

```bash
# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎨 Key Features Explained

### WhatsApp Integration
Floating WhatsApp button appears on all pages, allowing instant customer contact — critical for Indian B2B conversions.

### Multi-Step Quote Form
4-step quote request process:
1. Service type selection
2. Project details (quantity, material, timeline)
3. File uploads (drawings, images)
4. Contact information

### SEO & Structured Data
- Complete meta tags for social sharing
- JSON-LD structured data for LocalBusiness
- Canonical URLs
- robots.txt for search engine crawlers

### Gallery with Filters
Interactive gallery with category filtering and lightbox modal for detailed views.
